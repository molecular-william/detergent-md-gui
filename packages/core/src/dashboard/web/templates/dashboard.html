    What it is for
    In a CG (coarse-grained) model, each bead stands for a group of atoms. A torsion is the twist of four beads in a row. Bonds and angles hold a molecule's local shape; torsions decide how its chain bends and twists, and so which shapes it can take. A set that is too stiff or too soft changes packing and assembly even when every bond and angle is right. The choice is part of the model, not a detail.
    How it works, and what a run needs
    How it works
    The Fast-Forward fit measures each torsion's angle in every mapped AA (all-atom) frame, and the refinement reads those angles. Angles repeat every full turn, so the circular-harmonic model averages them on a circle instead of a line, and writes one preferred angle and one stiffness. The stiffness is k = kT / variance: kT is the thermal energy at the fit temperature, and variance is how spread out the angles are, so a narrow spread gives a stiff torsion and a wide one gives a soft torsion. The stiffness scale (0.1–3) multiplies k for every torsion it writes, which softens or stiffens the whole set without editing terms by hand. Legacy changes nothing: the fitted periodic terms stay as recorded.
    What a run needs
    A mapping with beads and declared torsions — Save to mapping puts the pair in the mapping file, and a run is queued from that file. An AA reference run with mapped frames: the harmonic fit needs at least three sampled angles per torsion, and a spread with one clear peak — when the angles have no single preferred direction, the fit refuses by name instead of guessing. A Fast-Forward fitted topology that has torsions; a topology with none is refused.
    Caveat. A stiffness that looks right is not established by this panel. The dihedral-fit analysis checks a legacy fit; it has no circular-harmonic reading, so no independent check is claimed for this model. Nothing here is scientific validation: a model that runs is not a model that is correct.
