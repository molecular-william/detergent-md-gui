Protein-Detergent Simulations

Place a membrane protein in a box, build a detergent belt around it, sample it, and assess whether a micelle formed.

DETERGENT

Choose a detergent

Detergents only. The list is the registry in detergents.json, so a molecule that is not a detergent cannot be chosen here. Every entry needs a saved CG mapping: the belt is built from the detergent's own beads, not from a generic template.

This template is a skeleton, and its own file says so: the repository has no fitted DDM parameter set, so a build from it is a setup exercise rather than a detergent model.

Mappings for other molecules are not offered here.

MEMBRANE PROTEIN

Choose or download a structure

Structures live in the OPM catalogue, which carries each protein's own membrane annotation: the half-thickness used by the estimate below, and the box the protein-extent build falls back to when a structure states no membrane.

An import reports the half-thickness it found, or says plainly that the file states no membrane.

RUN CONFIGURATION

Detergent belt and sampling

This workspace runs protein-detergent systems only, so this panel asks only what that pipeline reads: no AA reference, no mapping screen, no bonded fit. The detergent's own topology file is its parameterization.
