# Plans

Every implementation plan lives here, named `YYYY-MM-DD-<topic>.md`. This directory is the one home for plans:
`docs/design/` holds design records and intent, `docs/superpowers/specs/` holds specifications, and neither takes
a task list.

A plan states its status (`draft for review`, `approved`, `being built`, `built`), the acceptance criteria, and
the tasks in execution order. Execution records stay with the plan they belong to.
