What this deliberately does not do
  1. It does not let the trajectory move bead boundaries: the bead types are calibrated fragments.
  2. It does not fit a mapping to one trajectory and call it validated (the fit/evaluate split, C5).
  3. It does not change the 1.15 written into topologies; the measured factor is displayed (D5, C2).

Review notes · the decisions behind this layout

Taken by me so the review can be about judgement. Each is reversible, and the reversal cost is stated in the design note.

Decisions already taken
  1. D1 A new Mapping Validation tab, plus one line on the run card. The content belongs to a (molecule, mapping, AA run, CG run) quadruple, which is no existing tab's scope.
  2. D2 Four cards in this order: geometry, bonded terms, shape/volume, solution behaviour.
  3. D3 Comparison label and convergence line are part of each card; a figure without them is a layout bug.
  4. D4 Badges only for claims our own data supports (inside the AA range, inside ±2 stderr). The reference entry and any experimental target render as context, never pass/fail.
  5. D5 The ring expansion factor is measured against our AA and displayed; the 1.15 written into topologies does not change without a separate review.
  6. D6 No new colours, charts or vocabulary: the existing palette, cards, tables and Plotly figures.
