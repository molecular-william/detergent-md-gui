The first CG leg, and it is named for what happens to it: its end state is judged. Detergents not in the micelle are removed, and losing more than 10% of the requested count re-runs this leg from scratch with new velocities, up to three attempts.
Continues the system that survived, from its checkpoint (gmx convert-tpr -extend), so the total CG sampling is the two legs together. The assessment re-runs at the end, and this is the state that gets back-mapped.
Other run options

Every field starts as the reviewed profile's own number. Changing one overrides it for this run only and the manifest records what was used; an untouched field keeps the profile's value and the run records the profile name.

Output cadence

GROMACS writes these in steps. One value applies to every MD stage; the equilibration profiles keep their own tighter cadences unless overridden.

nstxtcout is the compressed-trajectory stride; newer profiles spell the same option nstxout-compressed. Full-precision nstxout, nstvout and nstfout stay off, as the profiles state.

Neighbour search and cutoffs

Reaction-field electrostatics, Verlet neighbour search: the coarse-grained profile's own scheme. The cutoffs are the numbers most often varied for a different box or bead set.

Thermostat and barostat

The ensemble targets. Production uses Parrinello–Rahman at 1 bar; the NPT equilibration leg keeps its own c-rescale barostat unless these values are changed for the whole run.

Salt, seed and box

The seed defaults to today's date (YYYYMMDD). Clearing it stops the run rather than letting one be chosen for it.

Execution

CUDA order, not nvidia-smi order. On this host CUDA_VISIBLE_DEVICES is unset and CUDA enumerates fastest first: 0 is the RTX 5000 Ada (af:00.0, 32 760 MiB), despite NVML/nvidia-smi's PCI-order index putting that card last. The three 2080 Ti cards follow at 18:00.0, 3b:00.0 and 86:00.0; their exact CUDA order is read from the same probe at implementation time. The full name, memory, PCI address and UUID stay in the option's tooltip and the run record, so the short label above is not the only place the choice is stated.

Not here on purpose: the integration time step is the reviewed profile's (20 fs CG production, 5 fs CG equilibration), as are the reaction-field scheme and the velocity-generation seed. Exposing them would make the panel a second physics profile.
