One card, three states. Controls and a short status line only.

What the compact card keeps

Kept

  • The three choices, as labels.
  • Eligible runs (with the ineligible one and its reason), size and seed.
  • One status line: how many conformations, from how many runs, and that a build is stored.
  • The stored-library list with key, size, sources and digest.

Removed

  • Per-option descriptions under each label.
  • The "how the library is built" details block and the "what the run records" block — those are the plan's subject, not the form's.
  • The explanatory paragraph above the runs and the long size hint.

Still to design (not drawn)

  • The first build's wait, and the refusal sentences (pool too small, source has a protein, digest mismatch, missing library) in the status line.
  • The empty stored-library state: "copy a library in, or build one from runs".
