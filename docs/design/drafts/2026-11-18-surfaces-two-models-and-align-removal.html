Surfaces: AA vs Simulated CG, and the Align tickbox removed

The surfaces calculation now measures two models: the atomistic reference and this run's own simulated CG trajectory. The mapped raw and mapped ring-scaled variants are removed; the mapping still supplies the bead radii and one first-frame correspondence used only to register the CG frame onto AA.

The trajectory form loses the Align trajectory checkbox. Fit and Group state the transformation directly and are never disabled.

Run view › Shape and volume › Surface area

The explainer names two models, the table shows the comparison the scene draws, and the caption says which row is this run's own data. An older attempt with mapped statistics on disk reads the same way: only the two compared rows are shown.

Run view › Trajectory

The Align trajectory checkbox is gone from the form. Fit and Group are the only fit controls; the default build is unchanged (no fit, no group).
