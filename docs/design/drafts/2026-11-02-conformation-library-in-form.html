Where the detergent-shape controls sit inside New run

This is one form, not a new panel and not a new tab: the protein-detergent workspace's New run page. The cards, in order, are the ones the page has today, with the new one marked. The shape controls are a sibling of Detergent, Membrane protein and Run configuration because they are another per-run build input, and the System preview beside them is the same preview the page already builds.

  1. Detergent — which molecule, template and saved mapping.
  2. Membrane protein — the structure, or no protein for an empty micelle.
  3. Run configuration — placement style, aggregation number, legs, removal and back-map.
  4. Detergent shape — one rigid conformation, a library built from micelle-only runs, or a library already stored in this workspace.

The card has three modes, and the third is what makes a pre-built library usable: a build-from-runs writes its result into the store, so it appears in the "existing library" list afterwards. The run records the mode, the key and the digest either way.

Fit and behaviour

How it fits

  • It is a card in the pdc feature's own New run fragment, rendered in place of the engine form, not a new workspace, tab or route.
  • It reads the detergent/template/mapping above it and writes the run's settings, `inputs.json` and manifest, exactly like the belt and legs do.
  • The preview beside it already answers to the card: its basis names the number of conformations and the key, never the coordinates.

Three modes, one store

  • One rigid conformation — the default; existing builds unchanged.
  • Build from runs — payload {runs, size, seed}; builds if absent, reuses if present, and stores the result so it becomes an existing library.
  • Existing library — payload {key, sha256}; used as-is, source runs not needed; a missing or edited file is refused.

What the implementation still needs (not drawn)

  • The first build's wait (one sequential read per source run) and its failure state.
  • The refusal sentences: pool smaller than the size, source has a protein, detergent/mapping mismatch, digest mismatch or missing file.
  • The stored-library list's empty state ("copy one in, or build one from runs").
