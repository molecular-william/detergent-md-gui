“PDC analysis”: one pdc tab for the CG detergent-paper metrics

The question this answers: “I have a completed protein–detergent run — where do I read the detergent-organisation data I would otherwise compute by hand, without the panel drawing conclusions for me?”

What this draft shows, and what it does not decide.
  • Replace, not add. The pdc workspace's fourth tab becomes PDC analysis. The old Complexes tab — its “Build a complex” form and its NGL system viewer — is retired; New run is the build path and Run view is the system view. The panel id stays complexes, so ?run= links and the pdcSetRun hook keep working.
  • Data only. No verdict, no mild/harsh label, no pass/fail, no trend/slope, no cross-run overlay. The reader interprets. Three CG-honest metrics are added to the existing pdc-structure: protein→tail RDF, protein–head / protein–tail contacts, and water–head / water–tail bead contacts.
  • Reuse. The existing shape, aggregation, RDF and contact measurements stay. RMSD/RMSF/Rg/energy come from the run's existing trajectory-overview; this panel does not recompute them.
  • CG only. No alpha-helicity and no hydrogen bonds: a Martini bead has no backbone torsions and no explicit hydrogen. Water contacts are a bead count, not the all-atom “hydration number”.
  • Every figure is a sample value typed in for layout. Real values come only from a published attempt on a real run.
  • Tunable thresholds are options, blank by default; the run's own contact distance (0.60 nm here) is the default contact cutoff.

Method, sampling, cutoffs
Method: one bounded sample of one production leg, extracted once with gmx trjconv, read by gmx gyrate (Rg), gmx rdf (radial distributions) and gmx mindist (bead contacts); the gyration tensor and the aggregation are the producer's own numpy pass; the run's own micelle criterion.
Sampling: 200 of 20,001 frames, stride 100, spanning the leg's whole length · frame spacing 25 ps as the file states it. A bounded sample, not a converged ensemble.
Cutoffs: micelle contact 0.60 nm (the run's own) · contact 0.60 nm · water 0.60 nm · radial maximum 2.0 nm, bin 0.05 nm. The effective values are recorded in the report; a blank option means these defaults.

What these numbers are, and are not.
  • A bounded sample, not an ensemble. 200 of 20,001 frames is 1% of the leg; the report states the frame count, stride and span so the claim can be checked without trusting it.
  • A fallback leg. The extension stage was skipped; the assessment leg is not the rebuilt system and is not comparable with a run that has an extension leg.
  • Bead contacts, not bonds. Water-bead contacts are not the all-atom hydration number; the report's definitions say so.
  • Nothing here is validation. scientifically_validated: false; no verdict, no threshold, no “mild/harsh” label, no trend.

Other states

The same tab, when the run or the record is in a different state. These are layout sketches; the numbers are samples or explicitly “not measured”.

1 · nothing computed yet

No pdc-structure record

The run is completed and selected, but no structure analysis has been published. The tab says so and offers the one action it owns.

Nothing computed yet. Shape, micelle size, radial distribution and bead contacts are read from one bounded sample of this run's production leg.

The 404 from GET /api/jobs/<id>/pdc-structure is a state, not a failure. The Run view's “Structure and interactions” section can also queue the same kind.

2 · an older v1 record

New metrics not measured

A record published before this change has the original shape/RDF/contacts, but no protein→tail RDF, no contact groups and no water contacts. The tab shows the old numbers and marks the new rows not measured; Compute is the way to extend it. No migration.

protein→tail RDF — not measured · contact groups — not measured · water contacts — not measured

3 · no protein

A detergent-only run (e.g. DDM micelle)

The run has no protein, so the protein–detergent interface is not defined. The protein rows are null, never a zero; the detergent-only RDFs, shape, aggregation and water contacts remain.

This run has no protein. The protein–detergent interface is not defined; only the detergent-only forms are reported.

The micelle shape and the head–head / tail–tail RDFs still answer; the protein–head and protein–tail rows say “not defined”.

4 · no trajectory-overview

RMSD/RMSF/energy not computed

The structure record is published, but the run has no trajectory-overview. The protein-shape block says not computed and offers Compute overview; the core kind caches its attempt as an ordinary analysis, and the Run view's Analysis card reads the same record.

RMSD — not computed · RMSF — not computed · energy — not computed
the result is cached and readable in Run view.

5 · a run that is not completed

Stop the run first

The picker lists completed pdc runs only. If a ?run= link names a running run, the tab says so; the analysis coordinator refuses a running run by design.

This run is still running. Analyses are queued on a stopped run. The tab will offer Compute when it completes.

6 · a running attempt

Queued, then published

The Compute button is disabled while the request is in flight. The tab polls the analyses summary; when the attempt finishes it refetches the record and the PNGs. A failure shows the attempt's own sentence, not a blank panel.

Queued · pdc-structure · one sample, one pass

A failed attempt leaves the previous published pair on disk; the tab says what failed and keeps the old data readable.

Your calls (settled)

The six open items are settled; this draft and the plan reflect them.

  1. Label — PDC analysis.
  2. Thresholds — the current defaults: 0.05 nm RDF bin, 2.0 nm r_max, the run's own 0.60 nm contact, 0.60 nm water.
  3. Dead route — remove /api/pdc/<job>/system.pdb with the retired panel.
  4. Old panel tests — retire them; the New run / Run view coverage stays.
  5. No trajectory-overview — a second Compute overview button; the core kind caches its attempt, and the Run view's Analysis card reads the same record.
  6. Figures — a separate PNG per plotted metric: RDF, protein contacts, water contacts, shape, aggregation; the overview keeps its own PNG.

Everything in this page is a mock. No panel, producer, route or test has been changed; the static numbers are for layout, and every one of them is labelled sample.
