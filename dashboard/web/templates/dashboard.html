How this workspace works

All mappings here are unvalidated drafts. Passing structural checks does not establish force-field accuracy.

Design: edit bead names, sizes, and atom indices below; the molecular overlay updates as you type. Validate: green checks require complete, connected assignments and plausible bead sizes. Parameterize: save a reviewed draft, then choose it in a new draft-smoke run to fit bonded terms and run an independent CG test.

Recognized hexopyranose sugars use canonical fragments, 15% longer intra-ring constraints and a central massless TC4 interaction site. Linkage terms are fitted from AA data. Other chemistry remains a provisional draft.

Reference and building-block registry

Canonical files stay under references/. The dashboard records hashes and evidence status; imported models are not validated automatically.
