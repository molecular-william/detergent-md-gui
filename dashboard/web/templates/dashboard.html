    Workflow

    Choose a mapping and one of its saved states, or start from the mapping draft. Generate a reference-informed draft, select two physical beads in the 3D diagram, then create and edit an interaction in the table. Save as new state preserves the selected state unchanged. Generated parameters are hypotheses and short validation is an execution check, not scientific approval.

    Functions select the GROMACS potential form; bond lengths are derived from bead geometry and read-only. Other parameters use the units shown in each row. Constraints and virtual-site parents remain read-only.
