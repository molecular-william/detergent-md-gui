# Dashboard test dependencies.
# The dashboard's scientific/runtime dependencies are provisioned separately
# (MDAnalysis, numpy, scipy, matplotlib, plotly, ... -- see docs/PROJECT_GUIDE.md).
# pytest-xdist is the optional test-runner accelerator; playwright and vermouth
# are imported by tests that exercise a rendered browser or the sugar topology
# path, so a fresh checkout needs them to run the full suite.
#
# mdtraj is not a test-only import. The pdc CG stage asks martinize2 for the
# protein's secondary structure with the bare `-dssp` flag, and vermouth answers
# that flag with mdtraj and with nothing else: `AnnotateDSSP(executable=None)`
# binds `run_mdtraj` when mdtraj can be imported, and otherwise runs an external
# DSSP binary, of which vermouth trusts only versions 2.2.1 and 3.0.0. So this is
# the one dependency that route needs, and without it the stage falls back to
# MDAnalysis' own DSSP and the route the Martini 3 tutorial documents is never
# taken (`unit/test_pdc_cg_step.py` covers both). It is declared here because this
# file is the repository's one requirements file.
pytest-xdist>=3.6,<4
playwright>=1.40
vermouth>=0.15
mdtraj>=1.9,<2
# pdb2pqr is not a test-only import either. It is the plan's step 1 -- the prepare stage's rebuild of a deposited
# structure's missing side chains and its protonation -- and the pdc pipeline shells out to it by name
# (`execution/adapters/pdc_preparation.py`). It is declared here because this file is the repository's one
# requirements file. A checkout without it builds every run whose protein is complete, and the step that a run does
# ask for refuses by name rather than substituting a rebuild of the repository's own.
pdb2pqr>=3.7,<4
# hypothesis is a test-only import, declared here because this file is the repository's one requirements file. It
# carries the property tests (`tests/dashboard/unit/test_properties_*.py`) over the surfaces a hand-written case
# does not reach: the mapping validator against arbitrary bodies, the term-bead reader against arbitrary text, and
# the MDP writer against any settings the adapter accepts. It earned its place on the first run -- the validator's
# property found a non-dict body reaching `data.get` before the isinstance check meant to catch it, so the function
# raised AttributeError where its contract is the ValueError a route turns into a 400.
hypothesis>=6,<7
